# HyperFrames extraction review

**Historical record.** Counts, hashes, candidate status and pending actions below
belong to the dated scope of this document. They are retained evidence, not the
current operating guide or a new approval. Use [Current Generator State](CURRENT-STATE.md)
for supported behavior, publication status and remaining acceptance boundaries.

The 2026-10-15 [verified inventory](HYPERFRAMES-INVENTORY.md) supersedes the earlier counts: 15 package manifests, 210 blocks, 237 registered components and eight examples. It indexes the local source tree and reviews the selected rendering primitives plus relevant timing, readiness, text, runtime-hash and pixel-QA boundaries. This is an integration review, not a line-by-line security certification of every dependency or Studio component.

| Area reviewed | Decision for Short Creator |
| --- | --- |
| Registry flowcharts, charts, counters and comparison primitives | Port cue-driven SVG motion into five existing visual kinds. Reuse input records and brand tokens. |
| Kinetic type, curtain wipes and directional seams | Integrated into opt-in cinematic flow, bar and comparison compositions; additional candidates are inventoried separately. |
| Core timing/adapters and count-up frame rows | Use the existing 30 fps clock; derive every state from time and preserve exact final numbers. |
| Engine/producer capture, media, runtime hashes and GPU parity | Keep the qualified native backend and existing hash/audio/frame checks. Extend browser sampling to every story beat. |
| Parser/linter, fonts, readiness and text fitting | Keep strict existing input/overflow gates. Wrap new SVG labels without truncation or silently shrinking approved typography. |
| Player, SDK, inspector, Studio and studio-server | No adoption: a separate editor/runtime would add maintenance without improving this requested output. |
| CLI, cloud adapters, shaders, media services and publishing | No adoption: unnecessary dependencies, infrastructure or external behavior for this local integration. |
