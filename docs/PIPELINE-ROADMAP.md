# Pipeline Completion Gates

[Docs index](README.md) | [Visual library](VISUAL-LIBRARY.md)

The v1 production template remains the stable baseline. This development pass
adds asset preparation without silently changing the encoder or scene contract.
See [visual-library qualification](VISUAL-LIBRARY-QA.md) for current evidence.
Do not describe the generator as fully completed until the applicable gates below
have observed evidence, not just documentation or a feature checkbox.

| Gate | Current state | Acceptance evidence |
| --- | --- | --- |
| Offline asset library | Implemented; see current qualification note | Catalog, bounded inputs, local previews, SVG/PNG exports, tests and visual QA |
| Production visual adapter | Pending | Opt-in scene schema; brand palette/fonts; original safe zones; caption-clock animation; legacy pixel regression; real encoded/audio QA |
| Optional FFmpeg backend | Pending in this repository | Explicit selection, capability checks, no silent fallback, multiple audio fixtures, clean-run proof and licensing inventory |
| Clean installation | Pending | Fresh dependencies and first render outside the maintainer's existing runtime |
| Independent operator | Pending | Another operator completes onboarding through reviewed MP4 from docs |
| Release qualification | Pending refresh | Current tests, artifact/source audit, runnable demonstration and explicit release approval |
| Copy and YouTube optimization module | Deferred | Separate supervised workflow; evidence-based research, factual review and approved metadata handoff |

The separate channel experiment is not a qualified backend in this public repo.
Do not import customer branding, recordings, host configuration or private metrics
as fixtures. Use neutral synthetic data with redistribution rights instead.

The next production adapter must treat icon/visual IDs as allowlisted data, not
paths or executable options. Vendor bytes and adapter source must participate in
drift detection. Existing scene output should stay unchanged. Never bypass the
implementation lock or rewrite old brand approvals to accept a new engine.

Editor UI, hosted services, automatic publishing and autonomous agents are outside
this completion scope. They are not prerequisites for a useful portfolio release.
