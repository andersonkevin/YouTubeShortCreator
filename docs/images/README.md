## Origin

The 12 layout-named PNGs are actual browser screenshots generated by this project's
initial native qualification. They use the illustrative **Signal Lab** name and
template example content. No customer screenshots, stock illustrations, external
brand logos, personal voice files or AI-generated artwork were imported for this gallery.

`template-preview.png` is the previously included code-policy qualification image.
It remains available as a reference; the expanded gallery uses the layout-named set.

All PNGs are 1080x1920. They are copied without retouching, compositing or resizing;
Markdown/HTML display dimensions only affect their presentation. Their code values
and outcomes are illustrations, not factual performance claims.

## Manifest

[manifest.json](manifest.json) lists the relative path, SHA-256, dimensions, scene
layout, illustrative brand and capture origin. Layout images also record their
sample time in the qualification episode. Source qualification runs and fonts stay
private; machine-specific paths are not stored in this public manifest.

```bash
python3 -B tools/check_docs.py
```

The documentation checker verifies the listed image bytes, dimensions and links.
This establishes integrity against the manifest, not third-party intellectual
property clearance or a digital signature from the original renderer.

## Rights and Reuse

These screenshots document project-authored layouts. They do not include font
binaries and do not grant rights to any font software used during rendering.
The illustrative wordmark is not presented as an available or registered trademark.
Check name and asset rights before adopting a mark for a real channel.

Do not replace these public screenshots with a private customer's renders without
explicit permission, a new provenance record and an image/content review.
