# Session Handoff Template

Store a completed note under private `session-notes/YYYY-MM-DD-NN.md` without
overwriting prior notes. This template records context, not an approval grant.

## Scope

- Date and selected channel: pending
- Episode and run IDs: pending
- Current stage: pending
- User-requested scope and decisions this session: pending

## Verified Evidence

| Workspace-relative artifact | Command or review performed | Observed result |
| --- | --- | --- |
| pending | not run | unverified |

## Handoff

- Completed and verified: pending
- Awaiting listening or visual review: pending
- Blockers and failed checks: pending
- Approval still required: pending
- Next concrete action: pending
- Files changed or created: pending
- External transmission, installation or deletion performed: none recorded

Only replace pending fields with observed facts. Distinguish source tests from
media QA. Link actual brand/run evidence and never infer publication approval.
